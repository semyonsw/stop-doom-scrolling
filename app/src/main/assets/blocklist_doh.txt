# DNS-over-HTTPS / DNS-over-TLS resolver hostnames.
#
# Blocking these is what stops a browser with Secure DNS switched on from
# resolving names outside the tunnel. It is not airtight - a client that
# hardcodes a resolver IP skips the lookup entirely - which is exactly why the
# browser URL check exists as a second layer.
#
# Note this does NOT cover Android's system-wide Private DNS setting, which
# bypasses the tunnel completely. The watchdog warns when that is switched on.
